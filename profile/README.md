## Products

| | What it does | Get it |
|---|---|---|
| **Blue Stream Controller** | Control vMix from your phone or tablet: inputs, transitions, audio, overlays, shortcuts — with live video of the Preview, the Program and your first 8 inputs. | [Google Play](https://play.google.com/store/apps/details?id=com.betheltechafrica.blue_stream_controller) |
| **Blue Stream Server** | Free Windows companion that runs next to vMix and connects the app securely (PIN pairing, local network). | [Download](https://github.com/blue-broadcast/blue-stream-server-releases/releases) |
| **BlueBroadcast account** | Manage your devices and your Premium subscription for all our apps. | [account.bluebroadcast.app](https://account.bluebroadcast.app) |

Blue Stream Server updates itself: every release is published here, and each update is **digitally signed** — servers only install updates signed by BlueBroadcast.

## Open source

We contribute to the [Open Media Transport (OMT)](https://github.com/openmediatransport) ecosystem, a royalty-free video-over-IP protocol:

| Repo | Content | License |
|---|---|---|
| [omtplugin](https://github.com/blue-broadcast/omtplugin) | OBS plugin fork — Tally and H.264 decoding | GPL-2.0 |
| [libomtnet](https://github.com/blue-broadcast/libomtnet) | C# reference implementation fork — H.264 path | MIT |
| [omt-h264](https://github.com/blue-broadcast/omt-h264) | H.264 pass-through proposal for OMT | CC-BY |
